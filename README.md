# nanopynix

[![Documentation](https://img.shields.io/badge/docs-nixidae.github.io-blue)](https://nixidae.github.io/nanopynix/)
[![codecov](https://codecov.io/gh/nixidae/nanopynix/graph/badge.svg)](https://codecov.io/gh/nixidae/nanopynix)

`pynix`, a Nix CLI in Python, with its command-line layer (`libpynix`) and its
language server (`pynix-lsp`). They run Nix through
[huggorm](https://github.com/nixidae/huggorm)'s bindings.

    pynix build --file . --attr hello
    pynix eval --expr '1 + 1'

[Documentation](https://nixidae.github.io/nanopynix/)
